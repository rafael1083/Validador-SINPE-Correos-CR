FLUJO COMPLETO: DESARROLLO → MAIN (GitHub) → PRODUCCION

================================================================================
PARTE 1: DESARROLLO (Windows 11)
================================================================================

PASO 1: Hacer cambios en el código
  - Editar archivos en src/
  - Probar localmente con: npm run dev
  - Verificar tests: npm test

PASO 2: Publicar cambios a GitHub (AUTOMATIZADO)
  - Ejecutar: 1.publicar.bat

  Este script hace AUTOMATICAMENTE:
    ✓ [1] Inicializa repositorio (si es primera vez)
    ✓ [2] Ejecuta npm test (validación)
    ✓ [3] Agrega cambios a rama 'dev'
    ✓ [4] Pushea cambios a GitHub dev
    ✓ [5] Sincroniza rama 'main' desde 'dev' (merge)
    ✓ [6] Pushea main a GitHub
    ✓ [7] Ejecuta npm install (actualiza deps)

  Flujo:
    - Si tests FALLAN: pregunta si continuar (S/N)
    - Si tests PASAN: continúa automáticamente
    - Si hay error: detiene y pide acción manual

  Resultado: GitHub main tiene los cambios listos

VERIFICAR (opcional):
  - Ir a: https://github.com/rafael1083/Validador-SINPE-Correos-CR
  - Ver que main tiene los nuevos commits

================================================================================
PARTE 2: PRODUCCION (Windows 10)
================================================================================

PASO 1: Descargar cambios desde GitHub
  - Ejecutar: actualizar_servidor.bat

  Este script hace:
    ✓ Limpia estado local (git reset --hard)
    ✓ Checkea rama 'main'
    ✓ Descarga cambios desde GitHub
    ✓ Instala dependencias Node.js
    ✓ Reinicia servidor automáticamente

  Resultado: Servidor en producción actualizado con cambios de main

VERIFICAR:
  - Ver que el proceso node está corriendo
  - Hacer curl a http://localhost:3001/api/transactions
  - Confirmar datos cargados

================================================================================
FLUJO RECOMENDADO PASO A PASO
================================================================================

EN DESARROLLO (Windows 11):
  1. Editar código
  2. npm run dev (probar)
  3. npm test (validar)
  4. Doble-click: publicarDesarrollo.bat
  5. Esperar confirmación ✅

EN PRODUCCION (Windows 10):
  1. Esperar a que dev termine (5-10 segundos)
  2. Doble-click: actualizar_servidor.bat
  3. Esperar a que reinicie (30-60 segundos)
  4. Verificar: http://localhost:3001/api/transactions
  5. Confirmar datos ✅

================================================================================
TIEMPO ESTIMADO
================================================================================

Desarrollo:   2-5 minutos (cambios + test + publicar)
Transición:   10-15 segundos (GitHub sincroniza)
Producción:   30-60 segundos (descarga + instalación + reinicio)
TOTAL:        3-7 minutos de inicio a fin

================================================================================
TROUBLESHOOTING
================================================================================

Problema: publicarDesarrollo.bat falla
  → Verificar: git status (sin cambios sin commitear)
  → Solución: git add . && git commit antes de ejecutar

Problema: actualizar_servidor.bat falla
  → Verificar: Conexión a GitHub
  → Verificar: Rama 'main' tiene cambios en GitHub
  → Solución: Ejecutar publicarDesarrollo.bat de nuevo

Problema: Servidor no inicia en producción
  → Ver logs en: C:\validador-sinpesXcorreos\data\
  → Reinstalar: npm install
  → Verificar: imap.txt con credenciales válidas

================================================================================
NOTAS IMPORTANTES
================================================================================

✓ publicarDesarrollo.bat usa merge (seguro, preserva historial)
✓ actualizar_servidor.bat usa --hard (limpia producción)
✓ Siempre publicar desde dev antes de actualizar servidor
✓ .gitignore protege: imap.txt, data/*.csv, .env
✓ Servidor escucha en puerto 3001
